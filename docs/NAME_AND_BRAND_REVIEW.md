# Name and brand review

Date: 2026-05-27

## Candidate name

**FactorGraph-ST**

## Suitability

- Communicates the project focus: graph-based spatial modeling with interpretable latent factors.
- Distinct from INSPIRE and HarveST, the selected public-code baselines.
- Suffix `-ST` clarifies spatial-transcriptomics scope.
- GitHub search for `FactorGraph-ST`, `FactorGraphST`, and `factorgraph-st` returned no exact repository-name collision during the 2026-05-27 check. One unrelated repository contained `FactorGraph` in a longer robotics/calibration name, so the exact ST-branded name remains acceptable.
- Web search for exact quoted variants returned no obvious exact-name paper/tool collision during the 2026-05-27 check.

## Branding boundary

FactorGraph-ST should not use INSPIRE/HarveST naming patterns for modules, figures, or claims. Baselines are cited as prior art and comparison targets only.

## Decision

Keep `FactorGraph-ST` / repository folder `factorgraph-st` for now. Re-check before public release or GitHub remote creation.
