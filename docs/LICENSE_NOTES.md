# Licensing notes

## Project license

FactorGraph-ST is released under the MIT license (see `LICENSE`). The project license applies only to source files in this repository.

## Baseline software licenses are separate

The baseline repositories listed in `BASELINE_REFERENCES.md` are independent projects with their own licenses. Cloning a baseline at a specific SHA does not import those licenses into this repository.

## INSPIRE code-reuse policy

INSPIRE was recorded with `GitHub licenseInfo: null` at scaffold verification time (see `BASELINE_REFERENCES.md`). Until the INSPIRE repository's software license is **explicitly resolved**, no INSPIRE source may be copied, adapted, or imported into FactorGraph-ST. Cloning the INSPIRE repository at a documented SHA for inspection is permitted; integrating any of its code is not. This policy is enforced by the pull-request checklist and `docs/PROVENANCE_CHECKLIST.md`.
